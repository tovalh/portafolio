### Site Stack

This portfolio is built with **Next.js 16 (App Router)**, **React 19** and **TypeScript**. Key features:

- **Internationalization** with `next-intl` — SSG per locale (`/es`, `/en`) with `hreflang`-based SEO.
- **Dark / light mode** persisted via `localStorage`.
- **Contact form** wired to a Next.js API Route using [Resend](https://resend.com).
- **Custom localized 404** page catching all unmatched routes.
- **Tailwind CSS v4** with custom animations (blob, float, shake) and design tokens.
